- [ ] Grupisanje kuća je praktično za izvođenje.

- [ ] Trase prate dozvoljene koridore i obavezne tačke.
- [ ] Zabranjena područja nisu presječena.
- [ ] Kapaciteti i rezerva zadovoljavaju projektna pravila.
- [ ] Drop dužine i optički budžet su prihvatljivi.
- [ ] Fiber schema, materijali i izvještaji odgovaraju potvrđenoj mreži.
- [ ] Snapshot je uspješno vratio stanje prije potvrde.
